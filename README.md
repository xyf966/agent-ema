# EMA Agent — source code

用于机电作动器离线故障分析的受控工具调用 Agent。此仓库仅发布 Agent/工具源代码、无密钥配置示例及必要说明。

## 代码结构

- `agent/`：LLM 提供商适配、受控执行循环、报告与证据校验、MATLAB 工作进程。
- `tools/`：数据检查、残差计算、异常定位、工况查询、适用条件查询和证据绘图六工具；含 MATLAB 数值核、schema、通用物理条件及测试代码。
- `evaluation/`：离线控制验证与研究侧评价程序。
- `scripts/`：Agent 运行入口、适配检查、本地模型服务和研究辅助代码。
- `configs/`：云端/本地模型配置示例；密钥仅从本机环境变量读取。

## 使用边界

仓库不包含 Simulink 模型、观测数据、任务集、案例索引、实验记录、运行日志、私有真值/评分资料、论文研究文档或模型权重。MATLAB 的 `tools/private/` 是数值实现目录，不是私有评价数据。

Python 代码使用标准库；原环境为 Python 3.12、MATLAB R2025a。完整诊断、历史审计及多数研究验证入口依赖本地观测、任务、清单和评价资料；仅克隆代码不能直接复现实验。生成/绘图辅助脚本也可能需要未发布的本地模型和结果。代码中的原有路径与实验编号为接口引用，不附带对应研究记录。

在本地准备匹配的数据与任务包后，从 `scripts/run_controlled_agent.py` 或 `scripts/run_stage4_agent.py` 进入受控流程。Agent 只能通过六个注册工具取证，不应获得全目录文件读取能力。已有观测分析工作进程只加入 `tools/`，不加载模型或执行仿真；不要对完整研究目录使用 `addpath(genpath(...))`。

云端密钥使用本机 `DEEPSEEK_API_KEY`，MATLAB 安装位置可通过 `EMA_MATLAB_EXE` 指定；不要将密钥或私有数据加入仓库。付费调用需显式使用原入口的 `--live`。仓库内配置经过删减，仅保留运行参数，不是原始实验冻结配置，不能替代本地冻结清单。

本次发布仅做源文件语法、排除范围、凭据格式、两套六工具 schema 哈希和配置加载检查，不新增 LLM 请求、MATLAB 调用或仿真，也不构成方法性能验证。
